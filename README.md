# Трекер

Личный трекер на одном сайте: таймер с паузой, годовой календарь с тепловой
картой, цели по часам и синхронизация между устройствами через Google-вход.

## Сайт

**https://laylakh.github.io/mygoals/**

Открывается в любом браузере — на телефоне, компьютере, планшете. Чтобы
данные были одинаковыми на всех устройствах, войди через Google (кнопка
«Войти для синхронизации» в шапке сайта) на каждом из них.
